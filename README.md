Work alongside Timmy, the lamb from Shaun the Sheep.

Enable Lock Position so you can still click through Timmy.

## Install

**Option 1 — Download the prebuilt app:**

Grab the latest `.dmg` from [Releases](https://github.com/birdf00t/timmy-for-mac/releases).

**Option 2 — Build from source:**
```bash
./build.sh
open Timmy.app
```
