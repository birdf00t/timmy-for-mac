# Timmy

macOS 데스크톱 마스코트. 키보드를 치면 손을 내려치고, 마우스를 움직이면 앞손이 따라간다.
외부 라이브러리 없이 AppKit + Core Graphics 만 사용하며, 캐릭터는 이미지가 아니라 벡터로 직접 그린다.

## 빌드

```bash
./build.sh
open Timmy.app
```

Xcode 는 필요 없고 Command Line Tools 만 있으면 된다.

## 배포

```bash
./build.sh && ./make-dmg.sh
```

`Timmy.dmg` 가 나온다. 창 안에 앱과 응용 프로그램 폴더 바로가기가 같이 들어 있어
드래그로 설치할 수 있다.

ad-hoc 서명이라 **다른 사람이 내려받으면 Gatekeeper 가 막는다.** 받는 쪽에서
앱을 우클릭 → 열기 로 한 번 허용해야 한다 (또는 `xattr -d com.apple.quarantine`).
공개 배포하려면 Apple Developer 인증서로 서명하고 공증(notarize)해야 한다.

## 아이콘

`Icon/icon.png` (배경 투명 PNG) 를 바꾼 뒤:

```bash
./Icon/make-icon.sh
./build.sh
```

투명하지 않은 영역만 잘라내 정사각형 가운데에 다시 앉히므로, 원본에 여백이 있어도 된다.
메뉴바 아이콘은 파일이 아니라 `AppDelegate.makeStatusIcon()` 에서 코드로 그린다
(템플릿 이미지여야 다크/라이트 모드에 맞춰 색이 바뀌고, SF Symbols 에는 양이 없다).

## 권한

전역 입력 감지는 macOS 가 **손쉬운 사용(Accessibility)** 권한을 요구한다.
첫 실행 시 안내창이 뜨며, 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 에서
Timmy 를 켜면 재시작 없이 바로 동작한다.

**다시 빌드하거나 앱을 옮기면 권한을 다시 켜야 할 수 있다.**
ad-hoc 서명이라 빌드마다 코드 해시가 바뀌고, 경로가 바뀌면 macOS 가 다른 앱으로 본다.
목록에서 Timmy 를 `−` 로 지웠다가 새로 추가하면 된다.

## 조작

메뉴바의 양 머리 아이콘을 누르면:

| 항목 | 설명 |
|---|---|
| 위치 고정 | 끄면 창을 드래그해서 옮길 수 있다. 켜면 클릭이 그대로 통과한다 |
| 크기 | 60% ~ 150% |
| 위치 초기화 | 화면 오른쪽 아래로 되돌린다 |

캐릭터·위치·크기 설정은 `UserDefaults` 에 저장된다.

커서를 캐릭터 위에 올리면 흐려진다. 창이 클릭을 통과시키므로 마우스 진입 이벤트를 받을 수 없어서,
이미 추적하고 있는 커서 좌표가 창 안에 있는지로 판단한다. 캐릭터가 창을 꽉 채우지는 않으므로
판정 영역은 가장자리를 조금 깎아 쓴다.

## 동작 방식

- **입력**: `CGEvent.tapCreate` 를 `.listenOnly` 로 연다. 입력을 가로채거나 변형하지 않는다.
- **좌/우 판정**: 키 코드의 물리적 위치로 나눈다 (`` ` ``1-5 QWERT ASDFG ZXCVB + 왼쪽 수정자 → 왼손).
  스페이스바는 양손이 번갈아 친다.
- **손 동작**: 평소에는 자판 위에 살짝 떠 있고, 칠 때 내려치면서 납작하게 눌린다.
  누르고 있는 동안은 내려친 자리에 그대로 머문다(= 꾸욱 누르는 모양).
  키 반복 이벤트는 무시한다.
- **붙박이 키 처리**: 다른 앱이 뗌 신호를 삼키면 키가 눌린 채로 남는다.
  전에는 1 초마다 `CGEventSource.keyState` 로 하드웨어 상태를 대조했는데,
  **실제로 누르고 있는 키를 눌려 있지 않다고 보고해서** 꾹 누르는 동안 손이 제멋대로 돌아갔다.
  그래서 폴링을 없애고 두 가지로 바꿨다 — 이벤트 탭이 꺼졌다 켜질 때(= 이벤트를 잃어버리는
  유일한 상황) 눌림 상태를 비우고, 그 외에는 60 초 넘게 눌려 있는 것만 버린다.
  다른 앱이 keyUp 을 삼켜 손이 굳는 걸 막기 위해, 키가 눌린 동안에만 1 초 주기로
  `CGEventSource.keyState` 와 대조하는 감시 타이머가 돈다.
- **최소 눌림 시간**: 트랙패드 탭투클릭은 눌림이 50~80ms 밖에 안 되므로, 그대로 두면
  손이 내려가기 전에 뗌 신호가 와서 아무 일도 안 일어난 것처럼 보인다.
  그래서 그림에서는 최소 120ms 동안 눌린 상태를 유지한다. 빠른 타이핑에도 같이 적용된다.
- **오른손이 오가는 규칙**: 평소 마우스 위에 있다가, **오른손 키**를 치면 키보드로 옮겨간다.
  마우스로 돌아오는 조건은 세 가지 — 마지막 오른손 키 후 **1 초**가 지나거나,
  그전에 **클릭·스크롤**이 오거나, **커서가 움직이면** 즉시.
  왼손만 치고 있으면 오른손은 할 일이 없으니 1 초 뒤 마우스로 돌아간다.
  커서 이동은 **키를 누르고 있어도 이긴다** — 손 없이 마우스만 혼자 미끄러지는
  그림이 더 이상하기 때문이다. 다음 오른손 키를 치면 다시 키보드로 온다.
  다만 4 포인트 이하의 미세한 이동은 무시한다 (손을 얹어둔 트랙패드가 흐르는 것 걸러내기).
- **마우스**: 캐릭터가 우리를 마주보고 있으니 마우스도 앞쪽이 우리 쪽을 향한다.
  몸통 뒷부분은 어차피 손등에 가려 보이지 않으므로 **실제로 보이는 것만 그린다** —
  버튼 앞면과 그 사이로 튀어나온 휠. 손등이 그 위에 얹히고 손가락이 아래로 뻗는다.
- **커서 추적**: 커서의 전체 화면 상 상대 위치(0~1)를 책상 위 영역에 매핑한다.
  세로 폭은 좁게 둔다 — 마우스패드가 없으니 넓히면 마우스가 책상에서 떠 보인다.
  이벤트는 초당 90 회로 솎아낸다.
- **좌/우 클릭 구분**: 기본은 동그란 주먹이고, 버튼을 누르면 손가락 하나가 아래로 삐죽 나온다.
  좌클릭은 왼쪽 버튼으로, 우클릭은 오른쪽 버튼으로 향하고, 누른 버튼에는 음영이 들어온다.
  손은 늘 마우스에 닿아 있다 — 들어올리면 사이에 빈 공간이 보인다.
- **스크롤**: 휠은 스크롤 양·방향을 **속도로 받아 관성으로 굴러간다.**
  이벤트가 올 때만 눈금을 옮기면 휠 마우스처럼 이벤트가 드문 입력에서 툭툭 끊기므로,
  매 프레임 속도만큼 돌리고 속도는 프레임당 12% 씩 감쇠시킨다.
  스크롤을 멈춰도 0.5 초쯤 더 돌다가 선다.
  트랙패드는 연속값(`scrollWheelEventFixedPtDeltaAxis1`), 휠 마우스는 단계값을 쓴다.
  **스크롤 중에는 손가락을 내지 않는다.** 손가락을 내면 휠을 덮어 버려서 굴러가는 걸
  보여 주지 못한다. 스크롤의 신호는 휠이 돌아가는 움직임 자체로 충분하다.
- **애니메이션**: 모든 값이 목표를 향해 매 프레임 수렴하고, 다 도달하면 타이머를 끈다.
  **입력이 없으면 렌더 루프가 아예 돌지 않는다.**

## 개인정보

키 코드는 왼손/오른손 판정에만 쓰이고 즉시 버려진다. 무엇을 입력했는지는 저장하지도,
어디로 보내지도 않는다. 소스 전체에 파일 쓰기(설정 제외)나 네트워크 호출이 없다.

## 구조

```
Sources/Timmy/
├── main.swift          진입점 (Dock 아이콘 없는 accessory 앱)
├── AppDelegate.swift   창·메뉴바·권한 처리, 입력을 뷰에 연결
├── InputMonitor.swift  CGEventTap 기반 전역 입력 감지
├── OverlayWindow.swift 투명 / 클릭 통과 / 항상 위 창
├── MascotView.swift    입력 → 애니메이션 값 보간. 그리기는 아래에 위임
├── Mascot.swift        캐릭터 공통 규약, 색 팔레트, 화면 배치
├── Stage.swift         캐릭터와 무관한 소품: 책상·키보드·마우스·휠·팔·손
└── SheepMascot.swift   양 몸통·머리·얼굴
```

### 캐릭터 추가하기

`Mascot` 프로토콜만 구현하면 된다. 필요한 건 색 팔레트, 어깨 좌표 두 개,
그리고 책상 위로 드러나는 상체를 그리는 함수 하나뿐이다.
책상·키보드·마우스·팔·손은 `Stage` 가 팔레트만 받아서 알아서 그린다.

```swift
struct DogMascot: Mascot {
    let palette = Palette(ink: ..., body: ..., limb: ..., limbLine: ..., accent: ...)
    let leftShoulder = CGPoint(x: 112, y: 104)
    let rightShoulder = CGPoint(x: 192, y: 114)
    func drawUpperBody(in ctx: CGContext) { /* 몸통·머리·얼굴 */ }
}
```

지금은 캐릭터가 양 하나뿐이라 `MascotView` 가 `SheepMascot()` 을 직접 들고 있고
메뉴에 선택 항목이 없다. 둘 이상이 되면 선택 목록과 메뉴 항목을 다시 넣어야 한다.
좌표는 모두 320×220 논리 캔버스 기준이고, 책상 상판은 y = 52 다.

표정 인식을 붙이려면 `MascotView` 의 상태 변수(`leftKeyDown` 등)와 같은 층에
표정 값을 하나 추가하고 `Mascot` 프로토콜에 넘기면 된다. 입력원은
`AppDelegate.wireMonitor()` 한 곳에서만 연결되므로 카메라 소스를 나란히 끼워 넣을 수 있다.
